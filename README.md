# HONMONO

HONMONO is a website for subculture enthusiasts, providing a place for anime, games and related topics. The current repository contains static HTML prototypes that will evolve into a full-fledged community portal.

## Planned Features

- Rotten Tomatoes-style rating system for anime titles
- User reviews and ranking lists
- News about upcoming releases and events

## Serving the site locally

You can serve the HTML files with a basic HTTP server. For example using Python 3:

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000/index.html](http://localhost:8000/index.html) in your browser.

Opening the HTML files directly in the browser also works, though some future dynamic functionality may require a server.
